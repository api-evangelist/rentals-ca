# Rentals.ca

> Rentals.ca is a Toronto-headquartered residential rental marketplace and the flagship brand of the Rentals.ca Network (Rentfaster.ca, Louer.ca, Rentboard.ca, RentCanada.com, TorontoRentals.com), owned and operated by Rentsync (formerly Landlord Web Solutions Inc.). The network's real developer surface is the Rentsync Partners portal ("LIFT System API"), which publicly names three APIs — REST, Ad Syndication, and Search — but gates all documentation behind an approved partner account. Rentals.ca itself publishes no developer portal, no OpenAPI, and no documented public endpoint; the consumer site sits behind a Cloudflare managed challenge.

## Access

- Access to the LIFT System API requires registering at the Rentsync Partners portal and submitting a written application describing what you plan to build. There is no self-serve key issuance and no anonymously reachable documentation.
- No RESO Web API or Data Dictionary certification, no OData $metadata document, no Universal Property Identifier, and no open dataset is published by the company. RESO does not apply to the Canadian rentals segment.

## APIs (named on the public partner portal; documentation account-gated)

- [Rentsync Partners REST API](https://partners.rentsync.ca/): "Get access to the underlying data structures of the LIFT System. Detailed Canadian rental information is just a request away." — listings / property records.
- [Rentsync Ad Syndication API](https://partners.rentsync.ca/): programming interfaces to "interact with rental industry professionals using Rentsync's Ad Syndication to manage their online advertising." — listing syndication / advertising.
- [Rentsync Search API](https://partners.rentsync.ca/): "Query the LIFT platform for specific information. It's a great way to get data for mapping applications." — listings search / geospatial.
